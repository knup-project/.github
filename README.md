# `.github` — knup-project 조직 공통 문서

이 레포는 **knup-project** 조직의 프로필과 **모든 레포에 공통 적용되는 기본 문서**를 담습니다.
개별 레포에 같은 이름의 파일이 없으면 여기 정의된 파일이 자동으로 사용됩니다.

## 📁 구성

| 경로 | 역할 |
|---|---|
| [`profile/README.md`](profile/README.md) | 조직 메인 페이지(`github.com/knup-project`)에 노출되는 소개 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | 공통 기여 가이드 (브랜치·커밋·PR 규칙) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | 행동 강령 (Contributor Covenant) |
| [`SECURITY.md`](SECURITY.md) | 취약점 제보 정책 |
| [`SUPPORT.md`](SUPPORT.md) | 도움받는 방법 |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | PR 템플릿 |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | 이슈 템플릿 (버그·기능 제안) |
| [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) | 실제 구현 아키텍처 문서 |
| [`docs/ROADMAP.md`](docs/ROADMAP.md) | 로드맵 · 마일스톤 · 백로그 |
